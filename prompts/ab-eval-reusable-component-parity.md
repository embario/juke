# Cross-Platform Reusable Component Parity

Ecosystem goal: Improve Juke ecosystem consistency by aligning one reusable UI primitive across web, iOS, and Android.

Evaluation focus: Tests design-system judgment, documentation quality, cross-platform comparison, and resistance to vague audits or cosmetic redesigns.

Review the repository handbook, web and mobile guidance, current reusable component tasks, and existing UI kit implementations. Promote this idea into an `ITERATIVE` task that audits one shared UI primitive across web UIKit, iOS JukeKit, and Android JukeCore, then implements a small missing contract, example, or test for the highest-value gap. Avoid full visual redesigns and avoid running all mobile apps unless the selected component change requires it.
